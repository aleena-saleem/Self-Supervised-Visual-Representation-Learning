# Self-Supervised-Visual-Representation-Learning

## Project Goals

- Learn visual representations without labels
- Implement SimCLR from scratch
- Evaluate using Linear Probing and kNN
- Compare CNN and Vision Transformer encoders
- Extend to video representation learning
